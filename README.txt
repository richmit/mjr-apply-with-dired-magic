mjr-apply-with-dired-magic
==========================

This Emacs package provides a single function:

    `mjr-apply-with-dired-magic'

The easiest way to install mjr-apply-with-dired-magic is to pull it directly from
GitHub:

     (package-vc-install (list 'mjr-apply-with-dired-magic
                          :url "https://github.com/richmit/mjr-apply-with-dired-magic"
                          :rev 'newest))
